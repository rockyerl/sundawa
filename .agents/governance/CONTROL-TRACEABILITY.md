# Traceability model

An *implemented and evidenced* control should be traceable using IDs, not prose resemblance:

`Business goal -> COBIT 7 relevant theme -> verified objective (licensed source) -> optional COBIT 2019 compatibility objective -> ISO/OWASP/NIST requirement -> project-specific control -> risk -> responsible/accountable role -> test/check -> evidence URI -> finding/remediation -> gate status -> independent review`

The crosswalk's `cobit7_objective_id` is deliberately null until human verification. Skill names are internal roles for review and must not be presented as official ISACA processes. Store a crosswalk validation log, edition, reviewer and date when official verification becomes available. Control effectiveness requires actual check results, not a reference to the standard.
