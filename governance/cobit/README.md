# COBIT 7 target, COBIT 2019 compatibility

- ISACA announced COBIT 7 on **2026-11-19**. New process-component activities, two design factors (Organizational Health Context and Information/Data Management Strategies), AI risk scenarios and an updated assessment model exist.
- COBIT 7 is the forward-looking governance framework, and details must be validated against authorized current publications before use in external audits. This repository **does not embed official COBIT 7 control/practice IDs**.
- `cobit2019-crosswalk.json` is an *internally proposed thematic crosswalk*, not an official 2019-to-7 conversion, and all `cobit7_equivalence` values intentionally stay `not-verified`.
- Its thematic mappings help select current AI Skills and control/evidence ownership; they are not proof of conformity.

Official ISACA: https://www.isaca.org/resources/cobit ; COBIT 7 release: https://www.isaca.org/about-us/newsroom/press-releases/2026/isaca-launches-updated-cobit-7-with-enhanced-assessment-model-and-modern-digital-platform
